## 浏览与筛选

- L1 / R1 切换顶部页面，A 打开当前游戏。
- 「收藏」采用 Horizontal Gallery Card，单排每页四张封面卡片。方向键左右选卡，在首尾卡片继续往外按时翻页，焦点落到相邻页靠近的一端。
- 「最近」沿用原游戏库的左侧列表、右侧封面预览。列表按最近游玩时间倒序排列，上下选择游戏并更新预览，左右翻页。
- 收藏和玩过的游戏可获取封面，缺图时在原位置显示占位。「游戏库」采用纯文本列表，每页两列四行，按行从左到右排列，每项显示游戏名、ROM 文件名及必要的状态。方向键上下选行、左右换列，在最外列继续往外按时翻页并尽量保留焦点所在行。
- 退出详情、取消筛选或扫描完成后恢复原游戏焦点。提交筛选回到第一页。后台扫描在页码左侧显示「扫描中」，列表、页码和焦点保持原位。
- 启动状态有「全部状态」和「仅可启动」，打开时选中当前状态。搜索无匹配时提供「修改搜索」和「清空筛选」，首焦点为「修改搜索」。若搜索命中的游戏都缺少依赖，提示切回「全部状态」。
- 最近空态提供「浏览游戏库」，游戏库空态提供「配置游戏库目录」。收藏或最近有记录但目录暂不可读时，提示检查目录并重新扫描。

## 开局、游玩与暂停

- 开局默认选中上次成功使用的槽位，首焦点为「开始游戏」。暂停首焦点为「继续游戏」，进度页只允许操作本局槽位。
- L1 / R1 切换「进度」与「快照」。焦点在快照行时，方向键左右翻页。
- 快照空态保留主操作。开局时可直接开始游戏，暂停时可生成快照、继续游戏或保存并退出。快照列表显示生成时间和来源槽位。
- 开局应用快照先选目标槽位，显示各槽位是否已有进度，再确认覆盖。成功后仍停留在开局页。暂停中应用快照会替换本局进度，成功后保持暂停。
- 删除快照只影响历史副本。开局删除进度会清空该槽位，暂停删除进度还会结束本局并停止自动保存。确认时默认聚焦「取消」，B 回到触发项。
- 游戏画面按核心比例等比放大。加载与失败在原位置反馈，保留焦点。

## 设置与导入

- 「设置」与「收藏」「最近」「游戏库」共用顶部 Tab bar。切换到「导入」等设置分类时，顶部继续选中「设置」。
- 设置左栏切分类，右键进入内容，B 回原分类。外观提供「更小」「默认」「更大」三档圆角，切换后即时生效。同步页说明存档目前仅保存在本机。
- 「关于」显示应用版本、更新状态和核心版本。检查期间禁用检查按钮。若有新版本，同一区域显示下载操作、进度与取消入口，下载校验通过后按 Android 提示授权和安装。
- 导入从「添加文件夹」打开 Android 目录选择器。「使用此文件夹」继续到系统授权确认，允许后返回应用扫描。退出选择器后恢复入口焦点。未添加目录时保留添加入口，已有目录时显示「重新扫描」与扫描统计。
- 每条游戏目录右侧都有可用手柄聚焦的「移除」按钮。A 打开确认框，默认聚焦「取消」。B 取消后回到原按钮，确认移除后焦点落到下一条目录的「移除」按钮，其次是上一条，没有目录时回到「添加文件夹」。目录中的原文件和存档保留。

## 规格与真机核对

- 面板圆角 20 dp，内距 8 dp，子面圆角 12 dp。模糊 18 dp。焦点描边 2 dp，外间隔 2 dp。
- 2026-11-21 在 RP6 上通过 ADB 操作已安装的 Debug 0.10.2。实测收藏、最近、游戏库、两种筛选空结果、缺少启动依赖、开局、游玩、暂停、存档确认、五个设置分类和 Android 目录授权界面。应用更新实测了检查中和已是最新版本。
- 收藏、最近与空库的初始空态、无目录、暂停快照空态及启动加载和 DAT 错误依据当前实现绘制。新版下载与安装、存储故障和实体按键手感尚未实测。
