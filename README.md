# FBNG

FBNeo Next Generation 是自用 Android 街机前端，仅适配 RP6 掌机。应用从启动起固定横屏，以内置手柄操作为主。应用通过 LibretroDroid 运行固定版本的 FinalBurn Neo，并用配套街机 DAT 识别游戏、父套件和 BIOS。

首次使用时，在「设置 → 导入 → 添加文件夹」选择存放 ZIP 的目录。仓库和 APK 都不包含游戏 ROM 或 BIOS，请使用自己持有的 ZIP。应用供个人使用。
