# Islands 界面与交互规则

FBNG 使用 Jetpack Compose 和 Material 3 深色方案。唯一适配目标是 RP6 掌机，操作以内置手柄为主、触屏为辅。

**只适配横屏。** APP 从启动起固定横屏，覆盖所有页面和弹窗。界面设计和真机验收以 RP6 横屏实际可用的窗口和系统安全区为准。`MainActivity` 的 `screenOrientation="landscape"` 与应用级大屏兼容属性共同声明此限制。

3 个固定槽位与独立快照的游戏页及覆盖确认规则见[横屏游戏页：槽位与快照](game-page-slots-snapshots.md)。

下面的字号、圆角、边距是建议起点。修改前先看现有界面。

## 视觉风格（Islands：极简主机启动器）

界面是 Islands 主机启动器：炭灰底、相互留出间距的圆角卡片、无衬线字。导航、固定标题栏、游戏卡片、设置分区和暂停页使用独立色调表面，不加阴影。复用 `ui/theme/Islands.kt` 的容器。

游戏详情和暂停共用横屏游戏页：左侧游戏及主操作，右侧「槽位 / 快照」局部标签。每款游戏固定显示 3 个槽位，只有开局前可以选择，本局自动保存目标不变。快照手动生成并独立保留，倒序分页，每页 3 张，不设产品数量上限。开局前应用快照可选择目标槽位；暂停时只能应用到本局槽位，并同步替换实际运行进度。删除当前槽位进度须确认结束本局且不再自动保存；删除快照不影响槽位。所有覆盖和删除确认默认聚焦取消。

界面的唯一强调色是电光蓝，用来做实心按钮、焦点描边、选中标记和进度。没有第二套强调色（原来的朱砂 `#C24223` 和黄铜已去掉）。错误仍用独立的浅红色，避免和「可以开始」混成同一个蓝。只有深色。`MainActivity` 用深色系统栏，`FbngTheme` 只套 `darkColorScheme`，没有动态色。

色值只写在 `ui/theme/FbngPalette.kt`，经 `Theme.kt` 进 `ColorScheme`。字号在 `FbngType.kt`，间距、圆角和焦点描边尺寸在 `FbngDimens.kt`。按钮用 `ui/theme/Controls.kt` 的 `FbngButton`。

- 背景 `background` = `#101318`。表面 `surface` = `#171C24`。更高一层是 `surfaceContainerHigh` = `#1E2530`，再往上是 `surfaceContainerHighest` = `#293140`。最亮的表面 `surfaceBright` = `#313A4A`。不要在这些深色上用深色字。
- 正文 `onBackground` / `onSurface` = `#F4F7FB`。次要正文 `onSurfaceVariant` = `#D5DCE6`。这两级在 `surfaceBright` 上仍超过 4.5:1。
- 电光蓝按钮 `primary` = `#206AFB`，按钮文字 `onPrimary` = `#FFFFFF`（约 4.65:1）。
- 电光蓝文字（选中的底部导航、已通过校验的状态）用 `secondary` = `#A9C4FF`。`primary` 贴在炭灰上大约只有 4:1，不够当正文，所以蓝色正文用 `secondary`，蓝色色块和描边用 `primary`。
- 左侧导航的当前页面和圆角大小的当前选项用 `primary` 实底与 `onPrimary` 文字，焦点可在各项间独立移动。
- 焦点描边是 2dp 的 `primary`。实心 `primary` 按钮上改用 `onPrimary` 亮边，否则蓝边贴着蓝底看不见。获得焦点或按下时，按钮和卡片保持原尺寸。
- 字体是无衬线（`FontFamily.SansSerif`）。正文和按钮 16sp，作为焦点标题的字不小于 20sp。
- 圆角由「设置 → 圆角大小」统一控制。更小为 8dp，默认为 12dp，更大为 16dp。壳层不显示底部 A 确认 / B 返回提示条。
- 导航：RP6 横屏下，窗口宽度 ≥ 600dp 用左侧导航栏，宽度 < 600dp 用底部导航栏。外边距统一 16dp，导航断点是 600dp 和 840dp（`shellWidth` / `shellUsesNavigationRail`）。medium 和 expanded 都使用 96dp 的紧凑左侧栏，图标在标签上方，四个按钮等高铺满侧栏。壳层优先把空间留给游戏内容。
- 导航依次是收藏、最近、游戏库、设置。「最近」按成功启动的时间倒序去重，保存在本地。收藏是启动首页。导入和同步从设置进入，标题显示「设置/导入」和「设置/同步」。新增游戏通过配置游戏库目录完成。同步页显示「即将推出」。设置也显示核心版本和许可。收藏与最近每页最多 4 张等大的封面卡片。宽而低的内容区用一行四列，其余空间足够时用两行两列。卡片等分可用空间，末页保留空格和相同尺寸。上一页、页码和下一页各自成岛，与标题并列。手柄 L1 / R1 可翻页。翻页后焦点留在原格位，空缺时聚焦第一项。收藏、最近卡片和游戏详情使用真实封面，联网时只为收藏或玩过的游戏静默获取；设置提供手动获取缺失封面和更新入口。收藏和最近的封面裁切填满图片区，无图时在原位置显示游戏名。收藏、最近和游戏库的卡片都打开同一个游戏页。「添加到收藏」和「取消收藏」在游戏页操作，从收藏返回时原卡片若已移除则聚焦相邻卡片。游戏页封面按原图比例显示。Banner 仍用文字。不要画假游戏，也不要放 ROM 画面。游戏库使用字母筛选和状态筛选。字母面板支持连续输入，输入时只编辑草稿，点击「完成」才计算并呈现结果，返回或关闭面板放弃本次修改。按中文名拼音首字母、中文名、英文描述、套件 ZIP 名和实际来源文件名匹配，忽略大小写。面板按可用宽高排键，A–Z、数字、点、下划线、连字符、退格、清空和完成须同时可见；零结果时也能继续编辑。
- 游戏运行时只有游戏画面和纯黑边，不显示常驻 HUD 或悬浮按钮，也不为控件缩小画面。系统返回（侧滑和返回键）以不透明的游戏页暂停游戏。开局前聚焦「开始游戏」，在同页选择 3 个固定槽位之一。暂停时主操作切换为「恢复」，提供生成/应用快照、删除进度和保存并退出。返回恢复游戏，保存并退出更新本局槽位并回到来源卡片。确认框打开时先关闭最上层。
- 游戏运行时方向键、摇杆和 A/B/X/Y 仍交给核心，壳层不抢。手动暂停时改由壳层接收，恢复后交还核心；Menu / Mode 是暂停快捷键，触屏按钮同样可用。壳层（游戏库、导入、同步、设置、缺核心）里，方向键和摇杆一次一格移动焦点，A 确认、B 返回。文本框里 B 只退出编辑。游戏库根页上的 B 不退出应用。

## Token

颜色、字号、间距、圆角从 theme 取，不在组件里新写死。

- 颜色用 `MaterialTheme.colorScheme` 的角色，成对使用 onX / X。正文对比度至少 4.5:1，按钮和描边这类非文字标记至少 3:1。`ui/theme/ContrastTest.kt` 锁的是现在这些配对。
- 字号用 `MaterialTheme.typography`。手柄距离下，新写的正文不要小于 16sp，作为焦点标题的字不要小于 20sp。最多一到两个字体家族。等宽只用于数字或计时，不用于普通标签。
- 间距以 4dp 为基准，新间距只用 4 / 8 / 12 / 16 / 24 / 32 / 48。屏幕外边距统一从 16dp 起。
- 控件、卡片、面板和对话框使用同一个主题圆角。切换设置时即时更新，焦点描边和内容裁切共用容器的形状。
- 层级用色调表面（surface container），不要给每张卡片铺同一块灰阴影。同屏最多两级。
- 壳层外边距统一 16dp，按钮最小高度 48dp，都在 `FbngDimens`。暂停页使用现有间距和按钮 token，不依赖黑边是否能放下控件。
- 游戏画面后面的纯黑是黑边底，不是表面色。继续用黑色，不要换成 `surface`。
- 动效不要在页面加载时逐块淡入上滑。这个工程的 Compose BOM `2026.09.00` 解析到的是 Material 3 **1.4.0**，没有稳定的 `MaterialExpressiveTheme`。不要为了动效去开实验 API。系统开了「移除动画」时，动画时长应为 0。

## 不能做的事

这些是交互和可访问性约束，不是视觉风格禁令。

- 在组件里新写 `Color(0x…)`，或在 token 之外新写一截魔法 `dp` / `sp`。
- 只有长按、滑动删除、悬停才能完成，没有手柄等价操作。
- 文案写「点击这里」「轻触这里」。同一动作全流程用同一个动词（「导入」「开始游戏」「存档」「读档」「退出」）。错误写原因和怎么修，不道歉。
- 关键功能只能靠 Start、Select 或 Menu。这三个键可以做快捷入口。
- 用 `isTablet`、屏幕英寸或机型名决定布局。

## 手柄焦点

壳层（游戏库、导入结果、缺核心）要能只用方向键走完。游戏运行中不要拦截：`GamepadBridge` 在有 `GLRetroView` 时把方向键、A/B/X/Y 和肩键交给核心，回中之后壳层才重新接收。

- 进入每个界面时要有确定的初始焦点（主操作，或上次的那一项）。`FocusRequester` 放在可聚焦修饰符之前，`requestFocus()` 放在 `LaunchedEffect` 里，key 是目标出现的条件。
- 返回、关掉对话框或横屏窗口变化之后，按稳定 id 恢复焦点。找不到就落到确定的后备项。
- 默认 A / Enter / 方向键中心键 = 确认，B / Back = 返回。文本框要能用 B 退出编辑，而不是退出页面。X、Y、L1、R1 可以做收藏、搜索、翻页，但不能是唯一入口。
- 壳层与弹窗共用 `GamepadInput`，对 `AXIS_HAT_X/Y` 和左摇杆做边沿检测，并合并同时上报的 D-pad 与 HAT。一次推动只走一格，回中后再走。游戏运行时，原始输入交给核心。
- 焦点态要隔一米能看见：用 2dp 的 primary 描边，实心 primary 按钮用 onPrimary 描边。焦点和按下时保持控件原尺寸，禁用态使用独立的颜色。不要只靠默认 ripple。同一时刻只有一个焦点。
- 方向优先用默认空间搜索。只对走错的边用 `focusProperties`。焦点项要滚进可视区，不要贴死边缘。
- 壳层、缺核心页面和暂停页有自绘焦点。暂停页默认选中「恢复」，取消确认后恢复到原操作，应用快照成功后聚焦恢复；游戏运行时方向键由 `GamepadBridge` 交给核心。

## 横屏窗口

布局按横屏可用窗口宽度分级，断点为 600dp 和 840dp。

- compact，宽度 < 600dp：底部导航。详情是独立整页。
- medium，600–840dp：使用紧凑 rail。游戏库分页铺满内容区，不常驻详情栏。
- expanded，宽度 ≥ 840dp：使用紧凑 rail。选择卡片后再进入详情。

壳层标题、筛选、上一页、页码、下一页和返回键都用 56dp 高的独立岛，彼此间隔 8dp。返回键位于标题左侧，筛选和分页位于标题右侧。各岛共用 `surfaceContainerHigh` 和主题圆角，按钮的 2dp 描边只在获得焦点时显示。页码只读。游戏库收窄时先用紧凑筛选标签，标题和控件放不下时，标题占首行，五个控件另起一行。

游戏库分两列，按列表可用高度每页放 1 至 5 行。卡片至少 48dp 高，末页保留同样的卡片尺寸。游戏名 20sp、文件名 16sp，各为单行，超长省略。窄卡优先显示游戏名和缺依赖提示，文件名移到详情。按列从上到下排列。上一页 / 下一页按钮和手柄 L1 / R1 都能翻页，焦点落在原格位，格位空缺时聚焦第一项。筛选变化回到第一页，窗口变化按套件名定位当前游戏所在页。进入游戏页聚焦主操作，关闭游戏页按来源和套件名恢复焦点。

壳层用 `shellWidth` / `shellUsesNavigationRail`（`LayoutPolicy.kt`）按上述断点选择布局。游戏画面由 LibretroDroid 按核心宽高比在安全区内居中。运行时黑边保持纯黑，操作集中在暂停页。`MainActivity` 已处理 `configChanges`，窗口变化和暂停恢复复用同一份 `GLRetroView`。
