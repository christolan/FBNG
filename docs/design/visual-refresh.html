01 — THESIS

三条不动摇的原则

在现有 token 内做精细化，不新增硬编码颜色、不放大尺寸、不动交互契约。高级感来自克制，而非叠加。
P / 01

表面说话，不用阴影

两级深色表面 + 12% 透明度的发丝描边勾勒「岛」。边界清晰却轻盈，摆脱 Material 默认灰块的笨重堆砌。

现状 · 每张卡片同色实块、无边界，靠明度差强行分层
P / 02

排版建层级，不堆字号

标题收紧字距、加重视差；正文坚守 16sp 与宽松行高；时间与计数统一等宽对齐。层级靠字重、字距与留白共同建立。

现状 · 20/16sp 两级字重偏弱，中文标题缺乏焦点感
P / 03

唯一的蓝，用在刀刃

电光蓝只着色「焦点 / 主操作 / 进度 / 选中」四类语义；正文蓝一律走 #A9C4FF。次要操作退为中性描边，蓝色因此更响。

现状 · 蓝色块面积偏大，主次按钮同质，焦点权重被稀释
从 · BEFORE

默认的平铺

  • 卡片是同色实心块，缺少边界语言
  • 字重单薄、字距松散，标题立不住
  • 封面尺寸小、裁切随意，不是焦点
  • 大量蓝色块，主次按钮视觉等价
  • 信息密度不均，留白无节奏
到 · AFTER

收束的秩序

  • 发丝描边 + 两级表面，边界轻而准
  • 字重对比 + 负字距，标题一米可读
  • 封面放大为视觉锚，游戏名覆于其上
  • 蓝只标焦点与主操作，次要退为中性
  • 呼吸感留白，标题与内容用空间分隔

Selected ≠ Focused

如何落地到代码

本稿所有改动都在既有 token 与使用规则内，无需新增颜色或尺寸常量。

表面语言 · Islands.kt

在 fbngIsland() 增加可选的 12% outlineVariant 发丝描边；卡片底用 surfaceContainer，选中态升到 surfaceContainerHigh。仍不加阴影。

排版 · FbngType.kt

标题样式加 letterSpacing = (-0.02).em 并提高字重对比；正文维持 16sp、行高 24sp；数字统一 tabular-nums。

按钮 · Controls.kt

新增中性 Outline 次级按钮的常态描边（沿用已有 restingStroke）；实心 Filled 焦点仍用 onPrimary 亮边。

封面 · GameCover.kt

放大封面区、统一 4:3 裁切与底部渐变遮罩，游戏名覆于其上；无图时同位置显示游戏名，不造假日美术。

强调色纪律 · 全局

蓝色仅用于焦点、Filled 主操作、进度与选中；蓝色文字一律 secondary (#A9C4FF)；错误保留独立浅红。

可访问性 · ContrastTest.kt

沿用锁定的 onX/X 配对；所有正文 ≥4.5:1、描边与非文字标记 ≥3:1。新稿未引入任何未测试配色。
