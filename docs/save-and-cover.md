# 存档与封面

## 存档

- 游戏暂停界面提供「存档」与「快照」两种游戏进度保存方案

## 存档

- 存档无需用户手动操作，会在游戏暂停时自动保存
- 多个用户可以使用不同的存档来隔离游戏进度
- 切换存档并加载游戏后，当前存档变为「游玩中」的存档
- 游戏开始前和暂停时，默认选中游玩中的存档，左侧同步显示存档进度截图

## 快照

- 快照需要手动创建，不会自动覆盖，也不会自动读取
- 快照用于保存关键时刻，比如重要 BOSS 战开始前，可以保存快照反复挑战
- 快照读取需要选择一个存档，如果是非空存档，快照生效时会覆盖原本的游戏进度

## 封面

- 每个游戏先确定当前游玩中的存档，获取对应存档的封面作为游戏封面展示
- 没有游玩中存档的游戏，使用游戏名 + 背景色组合而成的卡片作为封面
- 在进入游戏前和暂停时，右侧切换选中存档/快照时，左侧同步预览对应截图
