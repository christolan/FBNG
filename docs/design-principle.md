# 设计原则

- **「设计原则」由用户维护，章节禁止 Agent 修改**
- 省去多余的辅助标签和说明文字，让布局本身说明信息的层级和关系
- 审视每一处交互逻辑是否符合直觉
- 毛玻璃质感
- 同级别元素的圆角统一，父子元素的圆角同心
- 手柄优先，绝大部分场景都可以通过手柄非常舒服地完成，不依赖点触屏幕
  - 页面切换支持通过肩键完成
  - 列表翻页通过左右完成
  - 手柄控制移动焦点时，因为聚焦而新增的外边框不应被遮挡
  - 页面、Tab、单选项的选中态明确
- 加载状态等弹出式的内容不可以影响页面布局，导致页面抖动
- 不允许页面元素互相遮挡
- 页面同级别元素的职责统一
  - bad case：并列的按钮，前三个是 tab 切换器，最后一个是功能按钮
- 操作逻辑闭环
  - 可以添加的内容必须有删除的入口
