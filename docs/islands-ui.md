# FBNG 0.8.0 Islands 界面

用于横屏街机前端，手柄为主、触屏为辅。记忆点是炭灰底上的独立圆角分区和单一电光蓝焦点。设计沿用原有颜色、字号、间距和圆角，取自 `ui/theme`；不添加阴影、动态色和页面入场动画。参考本次确认的 Islands 稿，保留现有导航、游戏库分页和存档流程。

## 页面对应

| 页面或状态 | 实现 |
| --- | --- |
| 收藏、最近、空列表、文件准备失败 | 独立标题栏与等尺寸横滑封面卡片；空状态在可滚动的独立面板中 |
| 游戏库、零结果、状态筛选 | 每页 2 列 × 5 行，按列排列；所有页大小一致，筛选和分页仍在固定标题栏 |
| 游戏详情、缺少父套件或 BIOS | 独立详情面板；完整标题、真实封面、来源文件和启动条件，缺少依赖时进入目录配置 |
| 字母面板 | 所有字符和操作同时可见；零结果仍能编辑 |
| 设置、应用更新、游戏封面 | 按功能分区；等待、处理中、成功和错误复用同一区域，沿用现有状态与文案 |
| 导入、扫描、目录不可读 | 控制和状态归入面板，目录各自一张卡片；扫描时原有游戏库仍可访问 |
| 同步、核心与许可、手柄说明 | 保留现有入口和说明，同步仍显示即将推出 |
| 暂停、错误、自动存档状态 | 不透明暂停页，标题/说明、操作和状态分别成区 |
| 存档、读档、槽位为空或上限 | 自动存档固定在左侧，手动槽位横滑；新建卡片放在存档列表末尾 |
| 重置、覆盖与读档确认 | 沿用确认流程，默认焦点在取消；返回关闭当前面板 |
| 启动加载、DAT 错误、核心缺失 | 使用同一面板和按钮样式，保留原来的退出与错误处理 |
| 窄窗口和游戏运行 | 小于 600dp 使用底部导航；游戏运行时只有画面与纯黑边，操作集中在暂停页 |

## 新建槽位

- 卡片与手动槽位同宽同高，使用加号和文字；获得焦点才显示蓝色描边。
- 自动存档不参与横滑，也不能在存档面板中覆盖。
- 窄窗口中自动存档和手动卡片等宽收窄，保证右侧至少能完整显示一张卡片。
- 新建卡片与手动槽位在同一个 `LazyRow`，位置始终在末尾，读档时不显示。
- 连续新建、返回确认框后按稳定标识恢复焦点；先滚动到目标，再请求焦点。
- 10 个手动槽位用满后保留禁用的新建卡片和上限说明，焦点回到可用槽位。
- 保持原有存档目录、版本检查、原子写入及失败时保留旧文件的规则。
